## 6. 指标口径备忘（引用前必读）

- `P ≡ 156.25e6/fps` 是恒等式（W43 每拍无条件 +1），`193/P` 只是"帧率未达几何上限"的换算式，
  **不是线占空测量**（源：根 README.md 多处 2026-10-10 订正）。
- "三台仪器一致 ≠ 正确"——RATE 轮三台仪器量的是同一个缺陷（源：`_proj_10g/notes/P7B_RATE_RESULT.md` 订正块）。
- 32 位计数器 >2.86 Gbps 即 12 s 回卷 ⇒ 速率判据必须 mod 2³²（源：`_proj_10g/notes/P7B_STAGEB_MILESTONE.md` §1.3）。
- 演示 app 的 1.111 Gbps 是 app 结构天花板，不是快路径天花板（源：`_proj_10g/notes/P7B_WU_MILESTONE.md` §1.4）。
- 旧"TCP 臂 91.9% 丢失"= 读侧/突发容量（台架面），引用必须带"两轮读路径不同"这条（源：台账 §10-22-3）。
- **换流时序的 K0 判据必须三列连体引用**（`K0==0 ∧ breaks==0 ∧ 全流验完`）—— 任何只引"K0=0"的转述都丢掉防线
  （源：台账 §10-79 掩蔽注）。
- **两条不许混的读法**：历史相位错构型在 0x24 上"不可复现" ≠ "修复被证明"（两臂同绿不区分两臂）；
  "触发面被激励" ≠ "窗口命中"（源：`_proj_10g/notes/P7B_OPEN_ITEMS.md` §0-42 / §0-45）。
- 涓流连接的 `max n` 是 pcap 域截断值（整连接字节以 sink 侧兜底为准）—— 引用必须带此注
  （源：台账 §10-83 读法防线 C-1）。
- 10G TCP 线上载荷天花板 = **9.49285 Gbps**（1460/1538×10）；历史件常见的 **9.4935** 是 P7b 遗留的
  73 ppm 高值，引用时需带脚注（源：`p11_e05_latency_20261027/README_FOR_TL.md` M-3 处置）。
- 满载单连接的 sink 侧 Gbps 是主机墙钟口径，本轮实测墙钟可有 ~0.18% 阶跃 ⇒ 引用须带 **±0.2%** 误差棒；
  板域占空/速率一律用拍钟 ΔW43/156.25 MHz（源：同件 §2/§5.1）。
- **口角色（2026-11-05 新订）**：两个光口跑不同应用 —— .2（ch1/J8）= 8×app 口、.4（ch0/J7）= 单会话演示口；
  **任何"多连接"板级结论必须带口角色**：历史"8 连接并发上限 2–4"全部在 .4 口测得，对 8×app 不成立
  （.2 口干净态 8/8）（源：台账 §10-186；`p11_txstarve_20261103/REPORT_0x3B_diag.md`）。
- **HLS 槽探针口径（2026-11-06 新订）**："泄漏轮后打 N 个原始 SYN 看 W7 增量"量的是**空闲槽数**（W7 = 累计
  SYN-ACK 计数，不是空闲槽直读）；探针本身会留半开槽，收尾态不许再打（源：台账 §10-190/§10-191；
  `p11_synfix_20261105/RESULTS.md` §3/§7）。
