- 证据（按设计件字面方程推）：
  - `sw_now = SWC_OK && sw_ev && active && !closing && !sw_pend`。同槽 `ev_up` 在 **closing=1** 时到达（sw_now=0，因 `!closing`）或在 **active=0**（空闲）时到达（sw_now=0，因 `active`）：

  - 而 closing 态到达是**常态**：`rtl/app_pattern.v:496-501` 注释逐字"慢路径的拆连→重建间隔 ~70 拍，而 app 的收尾要等帧器把上一帧发完（~195 拍）⇒ 两事件天然共用同一窗口"——这正是 A3（构建 E）要修的场景，`tb/tb_app_cont.v:568-583`（A13a/A13b，k=40/240 < 收尾窗）就是它的判据。空闲态到达 = W3 完成后的所有重连（S0A 的 conn3/conn4"clean"正是旧设计在此态正确工作的读数）。

**H-2 E4"块体一字不动"与 E6 `sw_slot` 自相矛盾：应用拍 `act_id<=up_slot=up_pend_id`（陈旧/复位值），换流应用到错误槽**

**H-3 门臂 u_swc1 的"旧 RTL 必红"主张不成立 ⇒ 该臂是空判据；§1.4 纯 P-1 独立后果链过度推广**

- 位置：DESIGN.md §4.1 u_swc1 行与 §1.4 (P-1)。
- 证据：旧 RTL 上，单事件 `ev_up` 落在帧中段（`seg_sent≠0, !frm_wait`）⇒ 登记 pending ⇒ **其后第一个 `seg_sent==0` 拍是下一帧的 opener 拍**（收帧拍 `need==0` 时 `seg_sent==seg_len≠0` 故 `up_ok=0`；收帧支 :847-857 置 `op_pend<=1, seg_sent<=0`）⇒ opener 拍 `up_ok=1` 且 **`asm_go=0`（op_pend=1）⇒ 干净补做**（SEED 落地、无覆盖）⇒ 新会话首载荷字节 = `SEED>>24 = 8'h9E`。**⇒ 旧 RTL 在该臂上 bb0===8'h9E ⇒ 绿**。文档声称"旧 RTL 上该臂 bb0≠0x9E ⇒ 红"只对"事件恰好落在首字装载拍"成立——而那正是 u_swc0 的刺激面。

- 建议：u_swc1 判据改为"应用拍距事件拍 ≤ N 拍且中间无在飞帧继续交付"（测延时语义）或并入 u_swc0；§1.4 (P-1) 后果链按组合形态改写。

**M-1 conn0（S0A dport=54500, `off=2920` 无断点）是抓包头部丢失伪影 ⇒ "4/6 相位错、报告漏 conn0"微勘误错误；R=2920 失去依据**

- 位置：DESIGN.md §0-2 / §1.6 S0A 行 / §5.1（R 初值）vs `_proj_10g/notes/p7b_defect_board_20261011/runs/S0A_ghost_pcap.txt:45-52`。
- 证据（逐字段现读）：conn0 = 6 条中时间最早（t=2015.16，S0A 开跑后 26 ms）；**`syn=0`（SYN 未被捕获）**；**`first_seq=0x123461e1`**，而其它 5 条全部 `SYN seq=0x12345678`、首数据 seq=0x12345679 ⇒ `0x123461e1 − 0x12345678 = 0xB69 = 2921` ⇒ **恰好 2920 字节的数据段落在抓包之外**；S0A 用 4 文件环形抓 53 s（41 万段），回转必然发生。TCP seq 连续性强制：板端首数据 seq 必为 ISN+1，首个被捕获段在 ISN+2921 ⇒ 那 2920 字节**真的上过线**（否则对端栈要从 ISN+1 之后出现一个它无法命名的洞），只是没进 pcap。
- 关键推理：设 conn0 真实数据 D[0..N)，捕获流 c_i = D[2920+i]，对齐工具报 off=2920 ⇒ **D[k]=pattern[k] ∀k≥2920**。任何缺陷机制要与之相容，只有两类：①"连接本来就正确"（D[k]=pattern[k] ∀k）——完全相容；②"D[0..2920) 旧相位 + 恰在 k=2920 一次复位"——**与 RTL 结构不相容**：pending 事件必在第一个帧间隙（opener 拍）被消费，复位只可能落在帧边界（1460 的倍数处），2920 恰为 2×1460 看似可乘，但"事件挂起到恰 2 帧后才落地"要求它在第一个帧间隙时 `up_ok=0`——该拍 `seg_sent==0` 恒成立 ⇒ 不可能。P-3（复位被吃）则要求无复位 ⇒ D[k]=pattern[X+k] ⇒ X=0 ⇒ 等价于"复位发生过"=正确。**⇒ conn0 = 正确连接 + 2920 B 头部丢失是唯一机制相容读法。**
