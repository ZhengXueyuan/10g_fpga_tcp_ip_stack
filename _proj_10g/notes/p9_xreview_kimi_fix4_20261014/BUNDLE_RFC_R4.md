结论（4 条）：
1. **区间非空 ⇔ 严格 `rcv_nxt < 2³¹`** ✓ —— v3r3 括注改 `<` 正确；`rcv=2³¹` 时区间退化为空，与所附推导逐字吻合。
2. **目标向分歧存在性与区间非空性逐点重合**（`rcv ≤ 2³¹−1` 存在 / `rcv = 2³¹` 起不存在）⇒ 主句"目标向注入存在 ⇔ `rcv_nxt < 2³¹`"与两配方守卫自洽 ✓。
3. **同族 `≥` 改正确**：`rcv=2³¹` 时向上加 2³¹ 必越 2³²（`a ≥ 2³¹+1 ⇒ D = a−rcv ≤ 2³¹−1`），向下最远 `a=0 ⇒ D = −2³¹` = 等价域端点（同值）⇒ "恰好 `rcv_nxt = 2³¹` 也不存在" ✓；所附 `存在 ⟺ rcv+2³¹ ≤ 2³²−1 ⇔ rcv ≤ 2³¹−1` 推导 ✓。
4. 反向域附核：`rcv = 2³¹+1 / 0xFFFFFFFF` 时 `a=0` 均落入 `a<b ∧ d_mod∈(0,2³¹)`（分歧，D7 侧）——与注中"两条都没做就注入 ⇒ 只能构造出反向域"一致 ✓。
