## §1 R3-1（中，必折）：E13 守卫 `sw_pend` → `closing`

### 1.1 反例序列（拍级；kimi 构造 + 我方逐拍复核通过）

**五条件交集**：`frm_wait` 冻结态事件 → 收尾停滞（`m_tready=0`）→ **停滞期来异槽事件**（E6"最新优先"把请求交接）→ 收尾恢复拍 `tx_ok` 回升 → 应用拍。

| 拍 | 事件 | 状态（拍末） |
|---|---|---|
| **E** | frm_wait 冻结态**同槽** `ev_up`（`tx_ok=0`） | `sw_pend<=1, sw_slot<=ev_slot`（E6）· `up_pend_r<=0` · `closing<=1`（E7） |
| **E+1** | 收尾第 1 拍：close word 已呈现，**`m_tready=0`（停滞）**；**同拍来一个异槽事件** | E6 `else if (ev_other_act)`：`up_pend_r<=1, up_pend_id<=B`、**`sw_pend<=0`**（交接！）· `closing` **保持 1**（无人清） |
| **E+2** | close word 被消费（`m_tready=1`）⇒ W3 完成（拍末 `active<=0; closing<=0`）；**同拍 `tx_ok` 回升** | v2r2 守卫 = `!(SWC_OK && (sw_pend(0) ∥ sw_apply(0)))` = **1 ⇒ `:922` fire** ⇒ 抢置 `op_pend<=1` + 陈旧 `remain_nxt` 派生 `seg_len`（块序晚于 W3 ⇒ 覆盖 W3 的 `op_pend<=0`） |
| **E+3** | **应用拍**（`up_pend_r=1` ⇒ 换流到槽 B）：换流块全量重写 `seg_len/op_pend/op_sent`，**但 `op_beat` 在拍内 = op_pend(流浪值 1) ∧ !pw_valid ∧ !closing ∧ seg_len(陈旧)≠0 = 1** ⇒ opener 以 **E+3 拍内仍为旧值的 `act_id=A`** 呈现；`m_tready=1` ⇒ 被消费（`:941-942` 晚于换流块 `:745-746` ⇒ `op_sent<=1` 落地） |
| **E+4 起** | 槽 B 会话（act_id=B）的载荷逐字流进 **A 打开的帧** | **跨连接污染**（比同槽情形更毒：载荷上了错误的连接） |

### 1.2 为什么 v2r2 的论证① 为假（根因）

v2r2 §1 论证① = "事件拍起 `sw_pend=1` 直到应用拍 ⇒ 守门覆盖 `[E, 应用拍]` 全程"。**该命题的隐含前提 = "请求的持有者不变"**；而 E6 的"最新优先"允许 `ev_other_act` 在收尾在飞时把请求**交接**给 `up_pend_r`（`sw_pend<=0`）——**收尾与 `sw_pend` 的生命期在交接后分叉**（收尾仍在飞：`closing=1`）。
**真正的不变量 = `closing`**（覆盖"任意持有者"的收尾全程，含停滞），不是"哪个寄存器在持有请求"。

### 1.3 修法（一行；kimi 建议照收）= E13 新文本

```verilog
:922  - if (frm_wait && tx_ok) begin
:922  + if (frm_wait && tx_ok && !(SWC_OK && (closing || sw_apply))) begin
```

**论证（四支，逐支可核）**：
1. **窗口无缺**：危险窗 = `[E, 应用拍]`。`[E, T]`（T = W3 完成拍）内 `closing=1`（E+2 拍内 `closing` 仍是 1——拍末才落 0）⇒ 封死；**应用拍 T+1**：`closing=0` 但 `sw_apply=1` ⇒ 封死；T+2 起 `frm_wait` 已被换流块清 0（`:755`）⇒ `:922` 条件自然假。**无空隙**（应用延期由 I2 保证：持有者非 `sw_pend` 即 `up_pend_r` ⇒ 收尾完成拍必然 `up_ev=1 ⇒ sw_apply=1`）。
2. **覆盖"任意持有者"**：与 R3-1 的交接序列无关（守卫只看 `closing`）⇒ 停滞、交接、重复登记均不影响。
3. **普通 `ev_down` 收尾在 SWC=1 下天然正确**：无换流的 `ev_down` 收尾期间（`closing=1`）禁止 `:922` 启动旧会话下一帧 = 正确行为（该会话正在拆除；W3 独占该拍）——**不与"legacy 同款登记不修"冲突**（那是 `SWC_OK=0` 面）。
4. **默认关折叠**：`SWC_OK=0 ⇒ 门恒真` ⇒ 默认构建**逐位不变**（等价锚 19 文件/4 必异/9 臂照旧）。

**误杀面复核（我方独立枚举，与 kimi 判定一致）**：唯一被压制的合法情形 = "悬挂换流期间的旧会话帧启动"——那**本就是 N-1 危害本体**（不是合法路径）；正常帧间 `frm_wait ∧ tx_ok` 回升启动下一帧时 `closing=0 ∧ sw_apply=0` ⇒ 门照过 ✓。

### 1.4 该序列的登记（新增，供实施期与门侧引用）

**"收尾停滞期异槽事件交接"** = `frm_wait` 冻结态事件（同槽）+ `m_tready=0` 停滞 + 停滞期异槽事件（E6 交接：`sw_pend<=0`/`up_pend_r<=1`）+ 恢复拍 `tx_ok` 回升 + 应用拍 —— 五条件交集。**登记进 §5 未闭合面**（作为"守卫语义已由第 3 版覆盖"的历史记录，不再列为开放项）。
