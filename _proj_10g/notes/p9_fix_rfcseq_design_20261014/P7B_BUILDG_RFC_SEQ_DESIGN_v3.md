## §3 RFC 正确形式与改动（含"改 1 行"的穷举证明复核）

### 3.1 改法（方案 A：1 行表达式）

```verilog
// 现在 (rtl/tcp_rx.v:320)
wire        seq_lt   = (seq32 < ra_rcv_nxt);   // 重复/旧段 (回绕安全: 无符号比较)

// 改为 (RFC 793 SEQ_LT: $signed(seq32 - ra_rcv_nxt) < 0; 边界约定见本件 §3.3)
wire        seq_lt   = seq_diff[31];           // = (seq32-ra_rcv_nxt) 的模 2^32 差的高位
```

【事实】`seq_diff` 已存在于 `:311`（现读）⇒ **不新增任何"新的宽运算表达式"**（它的三处消费者在改后 = `:318` 相对比较 / `:350` 相对比较 / **`:320` 位抽头**）。
等价写法 `seq_diff[31] && (seq_diff != 32'd0)` **逐位恒等**（`d==0 ⇒ d[31]==0`；`d≠0 ⇒ 两版都 = d[31]`）
—— 它是**纯冗余**（v1 已证，本件复核成立）；**推荐版 1**，冗余项写进注释即可。

**方案 B（v1 列出并否掉；v2 维持否掉）**：保留 `seq_lt_abs` 只修 `ackresp` 一站 ⇒ ① `P7B_OPEN_ITEMS` 的"两处偏离"闭合不了；
② 两个语义相近的线网**下一个人极易接错**；③ 多一个 32 位比较器的成本。**v2 补充**：方案 B 恰好对应 §5.3 的 **M2 变异臂**
（"半成品"对照）—— 它的存在意义是**证明两条链都要修**，不是候选方案。

### 3.2 等价域证明（**复核记录**，2026-10-14 本机重做）

**命题**：设 `a, b` 为 32 位。若 `a−b` 作为**普通整数** ∈ `[−2³¹, 2³¹−1]`，则 `A := (a < b)` 与 `B := d[31]`（`d = (a−b) mod 2³²`）**逐位相同**。

**V2 复核（本机 Python，纯组合代数，非 xsim）**：
- 元穷举：`{0, 1, 2^k±1 (k=0..32), 0x7FFFFFFF, 0x80000000, 0x80000001, 0xFFFFFFFE, 0xFFFFFFFF, 0x40000000, 0xC0000000}` 交叉积
  **96×96 = 9216 对** ⇒ 核 `(A==B) ⟺ D∈[−2³¹, 2³¹−1]` ⇒ **falsifier = 0**。
- 随机抽样：`random.getrandbits(32)` 交叉 **200,000 对** ⇒ **falsifier = 0**。
- 端点：`D = −2³¹`（`a=0, b=0x80000000`）**在等价域内**（两版都 = 1）；`D = +2³¹`（`a=0x80000100, b=0x100`）**在差异域**（旧 0 / 新 1）✓。
⇒ 与 v1 §2.4 的证明、审查靶 2 的独立复算**三方一致**。

**V3 口径（分歧域的正式刻画；§0a-1 / §0a-10）**：

- **主口径（真差）**：设 `D = a − b` 为**普通整数**（不取模）。则 **`A ≠ B ⇔ D ∉ [−2³¹, 2³¹−1]`**
  （即 `D ≥ 2³¹` ∨ `D < −2³¹`）。**本文此后凡说"分歧域"一律指它**；一切施工/判据一律以它为准。
- **等价双侧式（若必须用 `d_mod = (a−b) mod 2³²` 表述）**：
  **`A ≠ B ⇔ (a > b ∧ d_mod ∈ [2³¹, 2³²)) ∨ (a < b ∧ d_mod ∈ (0, 2³¹))`**。
  ⚠️ **两侧的 `a>b` / `a<b` 限定不可省** —— `d_mod` **单独不能**决定分歧：同一 `d_mod` 在 `a>b` 与 `a<b`
  两种落点下分别是"分歧"与"同值"（例：`d_mod = 2³¹` 在 `a>b` 侧分歧、在 `a<b` 侧同值）。
- **本机复算（2026-10-15，纯组合代数）**：修正形与真差式在元值 96×96（9216 对）与 20 万随机对上 **0 falsifier**；
  **kimi 复核稿的两侧式（第一析取缺 `a>b` 限定）在同一元值集上 4291 falsifier / 20 万随机对 75143 falsifier**
  —— 首例即**普通旧段** `a=1000, b=2000`（`d_mod=0xFFFFFC18 ≥ 2³¹`，复核式判"分歧"，实际 `old=1/new=1` 同值）。
  ⇒ **v3 采用修正形，不采用复核稿的字面形式**（反纠记录 = §0a-10，依据 = 本行复算）。
- **与 §3.4 行 4 的关系**：反向域 = 第二析取 = 行 4 所属；其**行为显现条件**与 **RFC 合规方向**见 §3.4 行 4 注。

### 3.3 边界约定：`d = 0x80000000` ⇒ `seq_lt = 1`

裁定（沿用 v1 §2.2，**措辞按审查订正**）：
1. **逐字实现 `$signed(a−b) < 0`**（two's complement 直译）—— 不需要额外解释；
2. **零额外逻辑**（另一约定要加 32 位相等比较）；
3. **合法对端结构性到不了**（板通告接收窗 ≤ 61440 ≪ 2³¹）：`d = 2³¹` 只可能是畸形/伪造/跨协议误解；
4. ⚠️ **措辞订正（审查降级条）**：不再写"RFC 两种都允许" —— **RFC 1982 §3.2 对"恰好相差 2³¹"这一点是【未定义】的**
   ⇒ 正确措辞 = **"未定义 ⇒ 两种约定都不违规"**；RFC 793/5961 的"对不可接受段回 ACK"落在我们的选择侧。
5. 【需仿真】必须**钉进判据**：§5.3 的 **M3 臂**（边界约定反转）红点 = `{F5}`。

### 7.2 板测（**最小可判实验**；v1 的"≥4 GiB"口径作废；**注入口径 v3 订正 = §0a-2**）

**关键口径（v3 双侧/真差版）**：分歧域 = **真差 `D = seq − rcv_nxt`（普通整数）∉ [−2³¹, 2³¹−1]**（§3.2）。
**自然发生**需要"回卷点附近来一个旧段"（平均 ≈ 2 GiB，`2³²−ISN−1`）；
**强制注入不需要任何回卷**，但要**按分歧域的正确配方**构造（⚠️ **v2 稿的 `seq = (rcv_nxt − Δ) mod 2³², Δ ≥ 2³¹` 作废**：
本机复算 `rcv=0x100, Δ=2³¹+0x1000 ⇒ seq=0x7FFFF100` ⇒ `D = +2³¹−0x1000`（正、<2³¹）⇒ **等价域，A/B 空判据**；复核高-2 成立）：

- **构型**：板在**收数据**的上行流上（`rcv_nxt` 持续推进即可，**不必跨 2³²**；也不需要 4 GiB）。
- **注入（两条配方，任选一；均已本机逐例复算 ⇒ 目标向分歧 + `seq_lt_rfc=1` + 旧式 `seq_lt_abs=0`）**：
  - **配方 ①（减式，Δ 小）**：`seq = (rcv_nxt − Δ) mod 2³²`，**`Δ ∈ (0, 2³¹)` 且 `rcv_nxt < Δ`** ——
    用 `seq = 2³² − Δ + rcv_nxt` 展开 ⇒ `D = 2³² − Δ > 2³¹` ✓；`d_mod = 2³² − Δ ≥ 2³¹` ⇒ `seq_lt_rfc = 1` ✓；
    旧式 `seq_lt_abs = (seq < rcv_nxt)` = 假（seq 巨大）✓。
    例（复算过）：`rcv=0x100, Δ=0x40000000 ⇒ seq=0xC0000100, D=+0xC0000000, d_mod=0xC0000000` ⇒ `old=0/new=1` **分歧** ✓。
  - **配方 ②（加式，Δ 大）**：`seq = rcv_nxt + Δ`，**`Δ ∈ [2³¹, 2³² − rcv_nxt)`**（上限防 mod 回绕 ——
    ⚠️ `Δ = 2³²−1` 且 `rcv_nxt = 0x100` 时会绕到 `seq = 0xFF` ⇒ `D = −1` **落回等价域**，本机复算过）。
    例（复算过）：`rcv=0x100, Δ=2³¹ ⇒ seq=0x80000100, D=+2³¹, d_mod=0x80000000` ⇒ `old=0/new=1` **分歧** ✓；
    `Δ=0x80001000 ⇒ D=+0x80001000, d_mod=0x80001000` ⇒ 分歧 ✓。**（与 §5.4 的 xsim F5 同形 —— 两门口径一致）**
  - 段本身必须是**合法段**（同 4 元组 / flags=ACK / doff=5 / IP csum / FCS 正确 ⇒ 过 `base_ok`），
    payload 100 B（走"数据段"支；或 `plen=0` 走"纯 ACK"支，两支可分别测）。
- **两臂（板级 A/B = 两个位流）**：
  - **负臂** = 现役 **0x24**（修复前）：预期 **静默** —— 线上**无**板侧 ACK，`ΔW23`（`rx_stat_nonmatch`）**+1**；
  - **正臂** = 修复位流（**BID `0x26`**）：预期 线上**出现**一个板侧 ACK（`ack = rcv_nxt`），`ΔW23` **不增**（该类改落 `stat_drop_seq`）。
- **承重件（防"静默"是空判据）**：负臂的 `ΔW23 +1` 同时是"注入帧真被板收到并分类"的见证；正臂的 ACK 见证 = 对端嗅探器抓到板侧帧（`stall_probe` 已有 `POST_INJECT_BOARD_FRAME` 日志）。
- **前置**：`0x08 = 0`（`carrier=1`，否则板不发 ACK）· 一条 ESTAB 连接 · 对端 raw 注入路径可用（npcap/`AF_PACKET`）·
  注入帧的 `rcv_wnd` 无关（判据不含它）但**必须过 `base_ok`**（CAM 命中/标志/doff/长度/IP 校验）。
- **风险与限度（如实登记）**：① 人造段会进对端栈的视野吗？注入是**板收方向**（对端发），对端自己的栈**不参与**该帧 ⇒ 不影响对端状态机；
  ② 板侧 ACK 发出后**对端栈会收到一个"意外的 ACK"**（`ack = 板 rcv_nxt`，seq = 板的 `snd_nxt`）—— 在窗口内 ⇒ 通常无害（dup-ACK），**登记不排除**；
  ③ 若注入不可行/不可复现 ⇒ **板级口径 = "未观测到"（空判据）**，**不许**记 PASS/FAIL；
  ④ 本实验**只证分支选择**（回 ACK / 不回），**不证**"回卷长流不再受伤"（那需要自然发生或强制造界；**未测即未测**）。

### 7.3 与长流刀（S3/连续模式）的关系

现有长流工具链（`p7b_longsend`/`p7b_longflow_board` 族）**不需要改**：本刀的板级判别实验是**注入式**，与长流套件正交。
**未测项（如实）**：236 s / 62 次回卷的长流**本刀未复跑**（"未观测到"的旧口径仍然成立，**不许**升级成"不存在"）。
