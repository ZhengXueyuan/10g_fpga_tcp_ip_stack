## ⑦ 保留意见：要裁定"STG 在板上成立"，还缺什么

**已有（本刀内，已核）**：RTL 语义（模型 + 门 + BFS 三证）· 端口 0 改动（字符串级核实）· 单元门 8 臂（含突变极性硬门）· 环门 / p6e 复跑（值面旁证）· synth 检查点（pre-place）。

**缺 2 —— 板级 A/B（同板 · 同线 · 同工具 · 同参数 · 只换位流）**：
- **正臂 = 0x21 + `--paylen 1470`（相位 6）** ⇒ 期望 `ΔW70 == 0` + 内容逐字节（`MIR_VERIFY rc=0`）；
- **负对照臂 = 0x20 + 同协议**（**已有读数**：`ΔW70 = 750,882 B = K 的 49.883%`、抓取流与逐拍模型**逐字节全等**，`p8_board_0x20_20261011/REPORT.md`）—— ⭐ **它同时就是设计件 §6.3-2 要的"源确实稠密"的见证**（同一协议下它把旧结构打崩了）；
- **臂 A 复现（`--paylen 1472`）** 作对照：期望仍 `ΔW70 == 0`（相位 0 不受本刀影响）。

**缺 3 —— 字节账口径必须换新式**：0x20 轮收口用的是 "`pc + ΔW70 = ΔW11 − 6`（**累加器** 6 B）"；本刀后残余项 = **`acc_cnt_r + stg_cnt`（0..24 B）**。工具侧**不建恒等式**（已核）⇒ **板级报告里手写的账必须改口径**，否则**假红/假绿**（这正是头注释 `:37-38` 点名的风险）。

**缺 4（不是本刀，但会撞上）**：`K % 4` 硬门 vs `K % 8` 粒度（DESIGN §7-R3）—— 板级/工具若用 `K ≡ 4 (mod 8)` 的总字节数，会得到"安静的短读"。与本刀正交，但**同批做最省**。
