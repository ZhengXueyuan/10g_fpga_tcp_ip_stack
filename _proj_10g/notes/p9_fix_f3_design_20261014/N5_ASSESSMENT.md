## 2 判定语义（读数怎么解释——先钉这个，再谈实现）

- 现读 `rtl/vlan_strip.v:123`：`rsw = RESYNC_EN && acc && !(acc_f && rst_n)` = "弹出但未当帧内容收下"，**含复位窗口内的浪费**（`:124` 注释逐字）。
- ⇒ 语义 = **"DP 复位释放时 FIFO 队首非 SOP"的计数**：**连流稳态中 Δ>0 ⇒ 直接指向一次运行中重锁**（正是 F-3 的触发面）；⚠️ 但冷启动/工程性复位窗口也会计入 ⇒ 判读**必须带"窗口起点 = 复位释放"**（负向读法 = 长跑 Δ≡0 ⇒ "未观测到重锁"）。
- 量级预期：一次重锁 ≈ 丢 **1..7 字**（设计 §1；`W_snap` 类读数 26 → 窗口后推入 5 字那族）⇒ 32 位计数器**不会回卷问题**（重锁次数 << 2³²）。

## 3 候选实现点（回读 `rtl/vlan_strip.v` 现读）

- **首选 = 设计 (A7) 预留位**：端口表**末尾**追加 32 位输出（文件内已有标记 —— `:125` 行注释逐字"⚠️ 若做 (A7) 把这一行挪到端口表"）。现读核：树内 `vlan_strip` 例化 **21 处**（`grep "vlan_strip u_vlan_strip\|vlan_strip #("`，含 `board/wrapper_p4.v:940`（具名参数 + 具名端口）/ `sim/f3_resync/tb_f3_resync.v:191` / 各历史副本）—— **抽样逐处核过 = 全具名端口** ⇒ 追加**输出**对既有例化**零位移**（⚠️ 落地前仍按 v2 风险 R1 做**全量 grep 复查**）。
- 备选 A（更省端口线）：**1 位粘滞"重锁发生过"标志**（`resync_bad_ever`）—— 省 31 根线，但**快照成本不变**（字宽不省快照 FF），语义变窄（丢幅度，只剩二值）。
- 备选 B（**不建议**）：挤进既有字的空位 —— 破坏"一字一计数器"的读法口径（下游会按字段宽解错）。

## 4 代价（一次构建口径）

- 端口 + wrapper 接线：**0 新 FF**（计数 reg 已在，32 FF）+ 少量 LUT/线（现成先例：`vlan_stat_stripped` 本就接出到 wrapper 线、只是"UART 帧行未接"）。
- 快照字：**≈96 FF/字**（WU 轮口径 = `snap_cdc.hold_b` 32 + `dout_a` 32 + `snap_words_r` 阵列 32 **三份**）⇒ 几何 **NW 75 → 76 / 未实现地址 `0x15C` → `0x160`**；读侧同步（照 0x28 轮先例 = **63 处 / 20 文件**量级）+ `WLABEL` 补 W75 + 四件默认值链 + **BID bump**（0x28→0x29）+ 矩阵/双门/归档/定向 STA。
- ⚠️ **与本轮最紧的时序直接相关**：0x28 的**全局 WNS 宿主 = 快照阵列异步复位族**（`user_reset_reg → snap_words_r_reg[*]/CLR`，`+0.065` = 周期 **1.02%**；§10-80 已登记"**下一轮加逻辑的第一观察对象**"）—— 加任何快照字都在给这条族**加负载** ⇒ 本项与那条登记**同对象**，须**同批评估、同批定向 STA**（`p9_build_0x28/` 是现成对照面）。

## 5 与 E12 计数器族的复用可能

- E12 = `app_pattern` 四计数器（W71..W74；SWC 事件式；0x28 构建；读法 = **三态恒等式**）。**打包路线完全相同**（DP 域源 → 快照阵列 → 读侧链）⇒ 本项**可照抄** E12 的接线 / 读侧同步 / 门模板（省设计面）。
- **不能共享字**：E12 四字已被三态恒等式占满（事件式语义），且 E12 在 `app_pattern`、本项在 `vlan_strip` —— **复位语义也不同**（本项随 `dp_rst_n`，那正是重锁信号本身）⇒ **复用 = 流程级，不是逻辑级**。
- 同批候选（若有下一次构建）：N-5 + 0x28 遗留（快照阵列族定向 STA）+ mdio 未观测项（b18/force_rst 通路）—— 但**不许**与"改 RTL 的回归"混批（#57）。

## 6 结论（**建议，⛔ 不下裁定**）

**建议 = 待定 / 搭车不单独立项**：① 价值明确（当前**板上没有任何仪器能看见重锁**，本项是唯一便宜的**被动**探测器）；② 但"无验证路径" ⇒ 单独立项的验收面只剩"恒 0 不反证 + 结构正确性"两条，收益密度低；③ 建议**并入下一次必然要动的构建**（与任何 DP/快照改动同批，顺带把那条 1.02% 余量的族一起测），**是否采 = owner/TL 裁定**（对齐 N-4 的"登记待 owner 复核"口径）。
