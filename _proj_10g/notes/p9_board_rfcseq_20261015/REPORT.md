**每跑公共读数（三口径）**：

1. **板侧快照**（原件 `snap_pre.txt` / `snap_post_*.txt`）：
   - **`W23`（`rx_stat_nonmatch_TCP`）= 负臂 +3 / 正臂 +0**（逐跑见上表）；
   - `W54 app_mismatch ≡ 0`（7/7 跑，注入未污染数据内容）；`W53 app_rx_bytes` 逐跑推进（上行数据真在流）；
   - `W22`（pass）只随对端纯 ACK 走；`W55`（下行重传会话）有小幅 ambient 增量（下行方向，非本判据面）；`W68`（ack_adv）随下行 ACK 走；`W70 mir_drop_bytes ≡ 0`。
2. **注入器自带嗅探器（AF_PACKET，独立于 tcpdump）**：7 跑 × 4 注入 = **28 条注入全有见证**；`POST_INJECT_BOARD_FRAME` 逐帧带 `t/seq/ack/win/len/flags`；**延迟 0.024–0.590 ms**。
3. **抓包（tcpdump `-s 96`，静默窗；arming/丢包门）**：`captured == received`、`dropped by kernel = 0`（除 P27/P27F 两跑的尾部 3 包，见 §5-4）；独立复算（`rfcseq_pcap_analyze.py`）= **每次注入帧在 pcap 中命中 1 帧（IP-ID 标记逐帧符合）**，其后窗内：负臂 **0 帧**、正臂 **1 帧**（延迟 0.061–0.368 ms，纯 ACK `len=0 flags=A`）。

**⭐ 三条最强旁证（防"静默/ACK"是空判据）**：

- **(a) 板侧 ACK 的 ack 值 ≡ 注入器所用 `rcv_nxt`，逐位相等（7/7 跑 × 全部 ACK）** ⇒ 注入帧的构造基准与板实际 `rcv_nxt` 同一（配方相对量成立），且正臂 ACK 内容 = 设计件预测的 `ack = rcv_nxt` **逐字**。
- **(b) dup 生命探针（`seq = rcv_nxt − 1`、1 B；两版本 `ackresp` 同为 1 ⇒ 都应回 ACK）在 7/7 跑都回 1 ACK** ⇒ 注入通路、帧构造、板侧响应在同一次跑内被证明活着 —— 负臂的"静默"因此不是"没收到/没通电"。
- **(c) 安静门**：每次注入前板侧帧空档 **0.800–1.069 s**（预窗 ambient 帧 = **0，28/28**）⇒ 注入后出现的帧在时间上只能归于注入帧。
- **(d) 首注入之后整段抓包里的板侧帧计数**：负臂 = **1**（仅 dup 的 ACK）· 正臂 = **4**（dup+T1+T2+T3 各 1）—— 一个数字的总账。

**注入配方自证（每跑打印，设计件 §8.2-R8）**：三条全为 **目标向分歧域**（`D ∉ [−2³¹, 2³¹−1]`、`old=0 / new=1`，逐例实算，如 P26b：`seq=0xB9D272EB, rcv=0x49D272EB, D=+2147483648, d_mod=0x80000000`）。**可行性闸**：13 次连接尝试里 **6 次 `rcv_nxt ≥ 2³¹` ⇒ 判"目标向不可构造"重开连接**（= 设计件 §7.2 可行性注逐字执行；占比 46% ≈ 理论 ≈50%）—— 这同时是"注入**不**落到反向域"的防线（防伪阴性）。

## §5 异常与偏离（逐条）

1. **注入器 = 原型参数化**（不是原样跑原型）：见 §1。原型的 `seq` 写死 `isn+1`（等价域）⇒ 不参数化就构造不出目标向。**未自创配方**（两条式子/判据/前置逐字 = §7.2）；新增项 = seq 参数化、嗅探方向取反、分歧域自证、IP-ID 打标、quiet 门、dup 探针。**执行前已在 `EXEC_PLAN.md` §0b/§4-1 登记**。
2. **负臂取 `0x25` 而非设计件原文的 `0x24`**：设计件写 `0x24` 的理由是"当时的现役修复前位流"；`0x25` 同为 pre-RFC，且**与 `0x26` 只差 RFC 一刀**（F-3 只动 `vlan_strip.v`+`wrapper_p4.v`；`tcp_rx.v` 逐字 = 冻结前缀 `7517c949…`）⇒ **单变量**更强。派单允许此选择。`0x24` 本轮**未跑**（§6）。
3. **正臂跑两个**：设计件原文正臂 = `0x26`（已跑 2 次）；`0x27`（现役，含 RFC + R5）跑 3 次（零烧录 + 收尾复跑）。三者结论同形。
4. **⚠️ 抓包尾部丢包（2/7 跑）**：`P27` 与 `P27F` 的 pcap **缺最后 3 包**（= 最后一次注入 T3 的"注入帧 + 板侧 ACK + 对端内核 ACK"三连）；tcpdump 自报 `received 134887/134731`、`captured 134884/134728`、`dropped by kernel = 0`（差 3）。**成因未定位**：假设 = TPACKET_V3 的块在 SIGINT 时未退役（"received by filter"在核内计数、"captured"才是落盘）；首现后已给主抓包加 `-U`（逐包落盘），**降低了频次但未根除**。**影响面 = 零**：这两跑的 T3 见证由**注入器自带嗅探器**（第二条独立仪器）逐帧给出（`POST_INJECT_BOARD_FRAME … ack = rcv_nxt`），且**两臂各有完整 pcap 的跑**（正臂 P27R/P26/P26b 全 3 注入都在、负臂 N25/N25b 全 3 注入都在）。**不自行裁定，登记待查**。
5. **`p7b_snap.sh` 身份门"不补零"假红**：烧 `0x25` 后首次身份门以 `EXPECT_BID=0x25` 调用 ⇒ 与读回 `0x00000025` 字符串不等 ⇒ `ID_FAIL`（**板子是对的，是门错**；Stage C "大小写敏感假红"的同族，只差补零维度）。已用 `0x00000025` 重读 = `ID_OK`（原件 `burn/IDGATE_0x25_repair.txt`）；`burn_arm.sh` 已改为一律传 8 位补零（后续三次调用 ID_RC=0）。
6. **本地控制台 GBK 编码事故**：`P27R` 跑到 attempt 1 时本地 `peer_ssh.py` 写 stdout 遇 `⇒`（U+21D2）报 `UnicodeEncodeError` 而退出（RC=255），**对端脚本未受影响、继续跑完 attempt 4**；该跑的控制台留档只有 1 行错误（`runs_P27R_console.txt`），**判据读数全部来自对端逐跑原件**（已全量取回）。后续调用均加 `PYTHONIOENCODING=utf-8`。⇒ 轮内工具面一处坑（"本地编码会杀死采集面、而远端照样在跑"）。
7. **T3 的配方替代（轮内参数选择，响亮登记）**：`rcv_nxt ≥ 0x40000000` 时**配方① 的前提（`rcv_nxt < Δ`）不成立** ⇒ 注入器打印 `SKIP T3_recipe1 …` 并改用**配方② Δ = 2³¹+2MiB**（同为 §7.2 的式子）。替代发生在 N25/P26b/N25b/P27F 四跑；P27/P27R/P26 三跑 T3 = 配方①。
8. **`SYNC_CHECK … MISMATCH`（7/7 跑）**：注入器把"板 rcv_nxt（板帧 ack）"与"对端 snd_nxt（对端帧 seq+len 最大值）"做同步自检，两者差 −248 B ～ +59 KB。**成因 = 注入器嗅探器在流量期有丢帧（缓冲区/处理速率）**，不是状态失配：同跑内 **(a) 旁证**（板 ACK 的 ack ≡ 注入器 `rcv_nxt`）+ **(c) 第三次交叉**（`ISN+1+src 自报 tx` ≤ 板 rcv_nxt，差 60–75 MB = `kill -STOP` 后内核队尾继续发送的量，逐跑一致）三方互证。**登记：嗅探器在高码率下会丢帧（其见证只在静默窗内满信度）**。
9. **烧录第二锚偏离**：`impl_1/` 已被 `0x27` 覆盖（B1 同款情形）⇒ 不再用"归档件 == impl_1 原件"双锚，改 = **报告硬编码 WANT + 轮目录 `SHA256SUMS.txt` 记录值 + 文件尺寸**三重核。
10. **抓包口径偏离**：B1 = 全窗环形；本轮 = **静默窗抓包（`-s 96`）+ SYN 小抓包**（控体量）。已在 `EXEC_PLAN.md` §4-4 先登记。
11. **`pcap 命中注入帧 = 0` 的假象**：首版分析器用 **IP-ID 标记**定位注入帧，而**内核自选 IP-ID 偶发落入标记段**（P27 一跑 77 帧"假标记"）⇒ 分析器已改为**以 inject 日志的 `(seq, len)` 为主口径**、标记降为第三号见证。
12. **板侧零窗探针 ambient**：P27 的 pcap 里见到板的 1 字节 zero-window 探针（`seq = snd_nxt, len = 1`）在静默态出现（对端窗口 0 时的正常行为）；**注入窗内 28/28 无探针**（否则会与"目标 ACK"混淆；判别 = `len` 与时间相关）。
